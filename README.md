# Cosmic-Interaction-System

## 📋 项目概述
这是一个基于 **WebGL + MediaPipe + Three.js** 的实时手势识别与3D粒子交互系统。通过摄像头捕捉用户手部动作，实时驱动3D粒子形成不同的几何形状，并支持手势识别、颜色自定义、粒子效果调整等功能。

## ✨ 功能介绍

### 核心功能

#### 1. **实时手势识别**
- 使用 MediaPipe Hands 进行实时手部关键点检测
- 支持左右手独立识别和过滤
- 识别精度高，延迟低（<100ms）

#### 2. **手势数字识别（1、2、3）**
- **手势 1**：拇指收拢 + 食指伸展 → 显示数字"1"形状
- **手势 2**：拇指收拢 + 食指+中指伸展 → 显示数字"2"形状
- **手势 3**：拇指收拢 + 食指+中指+无名指伸展 → 显示数字"3"形状
- 识别到数字手势时，自动禁用交互，专注形状切换

#### 3. **多种3D粒子形状**
- **基础模型**（5种）：
  - 🔮 球体（Sphere）
  - ❤️ 爱心（Heart）
  - 🪐 土星（Saturn）- 带环形结构
  - 🌸 花朵（Flower）
  - 🍩 甜甜圈（Torus）
- **手势模型**（3种）：
  - 数字 1、2、3 的粒子形状

#### 4. **手部交互控制**
- **水平移动手掌** → 控制粒子系统左右旋转
- **张开/合拢手掌** → 控制粒子系统缩放和扩散效果
- 实时响应，流畅的动画过渡

#### 5. **粒子外观自定义**
- 🎨 **颜色选择器**：实时调整粒子颜色
- 📏 **大小滑块**：调整粒子尺寸（0.01 - 0.50）
- 支持 20,000 个粒子的实时渲染

#### 6. **左右手独立控制**
- 可单独启用/禁用左手或右手识别
- 支持双手同时检测和筛选
- 灵活的多手势场景支持

#### 7. **AI 描述生成（LLM 集成）**
- 集成 Google Gemini API
- 根据当前形状和用户提示，生成创意描述
- 支持指数退避重试机制，处理 API 限流

#### 8. **摄像头预览**
- 实时显示摄像头画面和手部关键点
- 可拖拽移动和缩放
- 支持快捷键隐藏/显示

#### 9. **快捷键支持**
- **X 键**：显示/隐藏控制面板
- **I 键**：显示/隐藏摄像头预览

## 🛠️ 项目实现

### 技术栈

| 技术 | 用途 | 版本 |
|------|------|------|
| **Three.js** | 3D 图形渲染引擎 | r128 |
| **MediaPipe Hands** | 手部关键点检测 | Latest (CDN) |
| **WebGL** | GPU 加速渲染 | 原生支持 |
| **Tailwind CSS** | UI 样式框架 | Latest (CDN) |
| **Google Gemini API** | AI 文本生成 | gemini-2.5-flash |
| **HTML5 Canvas** | 摄像头预览绘制 | 原生 API |

### 核心模块

#### 1. **Three.js 场景初始化** (`initThree()`)
```javascript
- 创建 WebGL 场景、相机、渲染器
- 配置 20,000 个粒子的 BufferGeometry
- 设置加法混合模式实现发光效果
- 初始化雾气效果增强深度感
```

#### 2. **粒子形状生成器** (`Shapes` 对象)
```javascript
- sphere: 球面均匀分布算法（Fibonacci Sphere）
- heart: 参数方程生成爱心曲线
- flower: 极坐标螺旋线生成花朵
- saturn: 球体 + 环形结构组合
- torus: 参数方程生成甜甜圈
- one/two/three: 贝塞尔曲线绘制数字形状
```

#### 3. **手势识别逻辑** (`onResults()`)
```javascript
- 检测手指伸展状态（通过关键点距离和Y轴位置）
- 识别拇指收拢状态
- 组合判断识别 1/2/3 手势
- 支持左右手过滤和优先级控制
```

#### 4. **交互计算** (`calculateHandInteractions()`)
```javascript
- 手部水平移动 → 旋转速度累积
- 拇指-小指距离 → 缩放因子计算
- 应用阻尼系数实现惯性效果
```

#### 5. **动画循环** (`animate()`)
```javascript
- 每帧更新粒子位置（平滑插值）
- 应用手势缩放因子
- 数字形状自动回正逻辑
- 添加噪声实现微妙的动画效果
```

#### 6. **摄像头初始化** (`initCamera()`)
```javascript
- 使用原生 getUserMedia API
- 避免 MediaPipe Camera 工具的兼容性问题
- 实现预览循环和手势识别循环
```

#### 7. **LLM 集成** (`callGeminiApi()`)
```javascript
- 调用 Google Gemini API 生成描述
- 实现指数退避重试机制（最多5次）
- 处理 API 限流和错误情况
```

### 关键算法

#### **Fibonacci Sphere 算法**（球体生成）
```javascript
const phi = Math.acos(-1 + (2 * i) / PARTICLE_COUNT);
const theta = Math.sqrt(PARTICLE_COUNT * Math.PI) * phi;
// 均匀分布粒子在球面上
```

#### **贝塞尔曲线插值**（数字形状）
```javascript
function quadraticBezier(p0, p1, p2, t) {
  // 二次贝塞尔曲线：B(t) = (1-t)²P0 + 2(1-t)tP1 + t²P2
  return {
    x: (1-t)²*p0.x + 2*(1-t)*t*p1.x + t²*p2.x,
    y: (1-t)²*p0.y + 2*(1-t)*t*p1.y + t²*p2.y,
    z: (1-t)²*p0.z + 2*(1-t)*t*p1.z + t²*p2.z
  };
}
```

#### **手指伸展检测**
```javascript
function isFingerExtended(landmarks, tipIndex, mcpIndex) {
  // 1. 检查指尖 Y 轴位置是否高于 PIP 关节
  const isTipHigherThanPip = tip.y < pip.y;
  
  // 2. 检查指尖与 MCP 之间的 3D 距离
  const distTipMcp = Math.sqrt(
    (tip.x - mcp.x)² + (tip.y - mcp.y)² + (tip.z - mcp.z)²
  );
  
  return isTipHigherThanPip && distTipMcp > 0.10;
}
```

### 性能优化

1. **粒子数量**：20,000 个粒子平衡视觉效果和性能
2. **BufferGeometry**：使用 GPU 缓冲区，避免频繁数据传输
3. **加法混合**：`THREE.AdditiveBlending` 实现高效的发光效果
4. **阻尼系数**：`DAMPING_FACTOR = 0.92` 实现平滑的物理效果
5. **插值平滑**：`lerp()` 函数实现帧间平滑过渡
